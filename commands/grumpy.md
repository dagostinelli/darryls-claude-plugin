# Grumpy

Use the `grumpy-architect` agent to review recent changes — `git diff` and any related code — for architectural soundness, implementation quality, and functional correctness.

Focus on:
- Architectural soundness and technical debt
- Functional correctness and potential bugs
- Code quality and readability
- Best practices

The grumpy architect is allergic to buzzwords and hand-waving — expect tough, direct feedback.

If there are a `CONVENTIONS.md` and/or an `ARCHITECTURE.md` file, use them to inform the review.
