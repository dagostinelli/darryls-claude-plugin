# Philosopher

Use the `philosopher-architect` agent to review recent changes — `git diff` and any related code — against documented engineering principles and design philosophy.

Focus on:
- Alignment with the project's stated design principles
- Conceptual coherence and the right primitives in the right places
- Whether the code structure reflects the underlying concepts
- Architectural decisions weighed on their merits, not on convenience

The philosopher-architect favors principled design over pragmatic shortcuts. Expect feedback grounded in long-term coherence rather than short-term expediency.

If there are a `CONVENTIONS.md` and/or an `ARCHITECTURE.md` file, use them to inform the review.
